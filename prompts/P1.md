## Prompt 1: solution/1 generator
Write a predicate solution(S) that generates a list of four terms p(Name,Dept,Lang,Project) in the order 'Alex','Ben','Carla','Dana', where each attribute uses each of its four allowed values exactly once (research, development, design, testing; python, java, 'c++', javascript; 'AI', web, embedded, data). Use permutation/2 from lists. Definitions only.

## Prompt 10: main/0 prints one solution
Write main/0 that finds one solution satisfying clues 1 to 8 (derived from the clues, nothing hard-coded) and prints exactly four lines in the format "Alex = [Dept, Lang, Project]" using write/format ~w, so 'c++' and 'AI' print without quotes.
## Prompt 11: count_solutions/2
