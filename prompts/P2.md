## Prompt 1: eval/2
Use my prolog-dev skill rules. Write eval(Expr, Value) for expression terms built from integers and e(Op,L,R) with Op in +, -, *, /. Division must be exact and the divisor non-zero; otherwise eval fails. Do this for every division inside the tree.

## Prompt 2: expr_of/2
Use my prolog-dev skill rules. Write expr_of(List, Tree), enumerating every expression tree over a non-empty list of numbers in order, by splitting the list into a non-empty left part and right part and combining with +, -, *, /. A single number is a leaf.

## Prompt 3: expr_val/3 
Use my prolog-dev skill rules. Make the generation of expr_of prune early: write expr_val(List,Tree, Value) that evaluates while building, so invalid divisions fail immediately.

## Prompt 4: fmt/2
Use my prolog-dev skills. Write fmt(Tree, String) that prints a tree as an SWI-Prolog string with no spaces using these rules: * and / bind tighter than + and -; left-associative; a left operand is parenthesised only if its top operator has lower precedence than its parent's;
a right operand is parenthesised if its top operator has equal or lower precedence; single numbers are never parenthesised.
Examples: 8/4*2, 8/(4*2), 1-2-3, 1-(2-3), 1+(2+3), (4+2)*3.

## Prompt 5: equation/2
Use my prolog-dev skills. Write equation(List, Str): for each split point j with 1<=j<k, a left tree over n1..nj and right tree over n(j+1)..nk with equal 5 values, returning "L=R" as a string.

## Prompt 6: generate_equation/2
Use my prolog-dev skills. Write generate_equation(List, Equation) that succeeds with one equation and fails (no loop, no error) for lists of length 0 or 1 or when none exists.

## Prompt 7: all_equations/2 and count_equations/2
use my prolog-dev skills. Write all_equations(List, Equations) using findall and sort/2 (no 7 duplicates) and count_equations(List,N).

## Prompt 8: P2 tests
Use my prolog-dev skills. Write tests for: [4,2,5,3] giving the seven equations in the spec, [2,3,4] giving [], [2,4,8] giving ["2*4=8"], [], [5], and a case with division by zero or inexact division.
